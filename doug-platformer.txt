======
RULES
======

(Revert dig pose on any directional input; preserve walk direction.
 Action while in dig pose stays in dig pose - handled in the dig rule.)
[ right PlayerR_Dig ] -> [ right PlayerR ]
[ left  PlayerR_Dig ] -> [ left  PlayerL ]
[ up    PlayerR_Dig ] -> [ PlayerR ]
[ down  PlayerR_Dig ] -> [ PlayerR ]
[ right PlayerL_Dig ] -> [ right PlayerR ]
[ left  PlayerL_Dig ] -> [ left  PlayerL ]
[ up    PlayerL_Dig ] -> [ PlayerL ]
[ down  PlayerL_Dig ] -> [ PlayerL ]

(Update facing when input direction reverses on the normal pose)
[ left PlayerR ] -> [ left PlayerL ]
[ right PlayerL ] -> [ right PlayerR ]

(Walk-intent markers - placed once at Doug's cell so we can detect
 a fully-blocked walk after movement resolves. If Doug moved, the
 marker is left behind at the old cell; if he didn't, the marker
 is still on top of him and the late rule fires the block animation.)
[ right PlayerR no TryR ] -> [ right PlayerR TryR ]
[ left  PlayerL no TryL ] -> [ left  PlayerL TryL ]

(Cancel vertical input - Doug only moves horizontally)
[ up Player ] -> [ Player ]
[ down Player ] -> [ Player ]

(Push: walking into sand shoves it one tile. Three-cell pattern so
 the rule only matches when the cell beyond the sand is actually
 clear - that way push never fires on a failed push, and the
 Pushed marker only appears on real pushes. Marker still gates
 climb-detect so multi-stack push doesn't trigger sand-step-up.
 The 'no Pushed' on the Player side prevents the rule from
 chain-pushing into a second sand on the same turn.)
horizontal [ > Player no Pushed | Sand | no Terrain no Sand no Player ] -> [ | Player Pushed | Sand ]

(Step up to the right - climb a one-tile ledge of Terrain or Sand.
 If the cell above the wall is Sand AND the cell beyond it is clear,
 Doug shoves that sand sideways and slides into its old position.
 ClimbR -> ClimbedR after the lift so the up-rule can't re-match
 and let Doug climb a second cell.)
right [ > PlayerR no Pushed | Solid ] -> [ ClimbR PlayerR | Solid ]
up [ ClimbR PlayerR | no Terrain no PlayerR no Sand ] -> [ | ClimbedR PlayerR ]
right [ ClimbedR PlayerR | no Terrain no PlayerR no Sand ] -> [ | PlayerR ]
right [ ClimbedR PlayerR | Sand | no Terrain no Sand no Player ] -> [ | PlayerR | Sand ]
[ ClimbR ] -> [ ]
[ ClimbedR ] -> [ ]

(Step up to the left - same cascade mirrored)
left [ > PlayerL no Pushed | Solid ] -> [ ClimbL PlayerL | Solid ]
up [ ClimbL PlayerL | no Terrain no PlayerL no Sand ] -> [ | ClimbedL PlayerL ]
left [ ClimbedL PlayerL | no Terrain no PlayerL no Sand ] -> [ | PlayerL ]
left [ ClimbedL PlayerL | Sand | no Terrain no Sand no Player ] -> [ | PlayerL | Sand ]
[ ClimbL ] -> [ ]
[ ClimbedL ] -> [ ]

(Dig: action button. Terrain or Sand in front becomes Background;
 a Sand drops into the empty cell behind Doug. Doug switches into
 the dig pose and a DigT3 marker starts the 3-frame animation.)
right [ no Terrain no Sand no Player | action RightFacing | Diggable ] -> [ Sand | PlayerR_Dig DigT3 | ] again
left  [ no Terrain no Sand no Player | action LeftFacing  | Diggable ] -> [ Sand | PlayerL_Dig DigT3 | ] again

(Dig blocked: action pressed but dig didn't fire. Show 3 frames of
 the opposite-facing sprite ONLY when the dig is clearly hopeless -
 nothing diggable in front AND no fresh sand behind. The 'no Sand
 behind' guard silences the spurious turn-around that auto-repeat
 used to trigger right after a successful dig.)
right [ no Sand | action PlayerR | no Diggable ] -> [ | PlayerL RightFlag BlockT3 | ] again
left  [ no Sand | action PlayerL | no Diggable ] -> [ | PlayerR LeftFlag BlockT3 | ] again

(Dig animation: advance one tick per turn. DigLock blocks subsequent
 ticks from cascading within the same turn; the late rule below
 strips it at end-of-turn so the next 'again' pass can advance.)
[ DigT3 ] -> [ DigT2 DigLock ] again
[ DigT2 no DigLock ] -> [ DigT1 DigLock ] again
[ DigT1 no DigLock ] -> [ DigT0 DigLock ] again
[ DigT0 no DigLock PlayerR_Dig ] -> [ PlayerR ]
[ DigT0 no DigLock PlayerL_Dig ] -> [ PlayerL ]

(Block 'no dig' animation cascade - same shape as DigT, separate
 markers. RightFlag/LeftFlag remember the original facing so the
 revert can restore it.)
[ BlockT3 ] -> [ BlockT2 BlockLock ] again
[ BlockT2 no BlockLock ] -> [ BlockT1 BlockLock ] again
[ BlockT1 no BlockLock ] -> [ BlockT0 BlockLock ] again
[ BlockT0 no BlockLock RightFlag PlayerL ] -> [ PlayerR ]
[ BlockT0 no BlockLock LeftFlag PlayerR ] -> [ PlayerL ]

(Gravity for Doug)
late down [ Player | no Terrain no Player no Sand ] -> [ | Player ]

(Gravity for sand)
late down [ Sand | no Terrain no Player no Sand ] -> [ | Sand ]

(Failed walk: TryR/TryL marker still on Doug means he did not
 move - fire the same opposite-facing animation as a failed dig.
 Fires AFTER gravity so a walk-off-ledge counts as success.)
late [ TryR PlayerR ] -> [ PlayerL RightFlag BlockT3 ] again
late [ TryL PlayerL ] -> [ PlayerR LeftFlag BlockT3 ] again

(Clean up orphan walk-intent markers - Doug moved past them.)
late [ TryR ] -> [ ]
late [ TryL ] -> [ ]
late [ Pushed ] -> [ ]

(Clear animation locks at end of turn so the next 'again'
 pass can advance the counter by one step.)
late [ DigLock ] -> [ ]
late [ BlockLock ] -> [ ]

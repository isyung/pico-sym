======
RULES
======

(Update facing when input direction reverses)
[ left PlayerR ] -> [ left PlayerL ]
[ right PlayerL ] -> [ right PlayerR ]

(Cancel vertical input - Doug only moves horizontally)
[ up Player ] -> [ Player ]
[ down Player ] -> [ Player ]

(Push: walking into sand shoves it one tile in the same direction)
horizontal [ > Player | Sand ] -> [ > Player | > Sand ]

(Step up to the right - climb a one-tile ledge of Terrain or Sand.
 If the cell above the wall is Sand AND the cell beyond it is clear,
 Doug shoves that sand sideways and slides into its old position -
 the noise2 sand-step-up traversal of a 2-stack obstacle.)
right [ > PlayerR | Solid ] -> [ ClimbR PlayerR | Solid ]
up [ ClimbR PlayerR | no Terrain no PlayerR no Sand ] -> [ | ClimbR PlayerR ]
right [ ClimbR PlayerR | no Terrain no PlayerR no Sand ] -> [ | PlayerR ]
right [ ClimbR PlayerR | Sand | no Terrain no Sand no Player ] -> [ | PlayerR | Sand ]
[ ClimbR ] -> [ ]

(Step up to the left - same cascade mirrored)
left [ > PlayerL | Solid ] -> [ ClimbL PlayerL | Solid ]
up [ ClimbL PlayerL | no Terrain no PlayerL no Sand ] -> [ | ClimbL PlayerL ]
left [ ClimbL PlayerL | no Terrain no PlayerL no Sand ] -> [ | PlayerL ]
left [ ClimbL PlayerL | Sand | no Terrain no Sand no Player ] -> [ | PlayerL | Sand ]
[ ClimbL ] -> [ ]

(Dig: action button. Terrain or Sand in front becomes Background;
 a Sand drops into the empty cell behind Doug. Requires empty behind.
 We check absence of solids instead of asserting Background, so the
 rule never removes Background from the dig-behind cell.)
right [ no Terrain no Sand no Player | action PlayerR | Diggable ] -> [ Sand | PlayerR | ]
left  [ no Terrain no Sand no Player | action PlayerL | Diggable ] -> [ Sand | PlayerL | ]

(Gravity for Doug)
late down [ Player | no Terrain no Player no Sand ] -> [ | Player ]

(Gravity for sand)
late down [ Sand | no Terrain no Player no Sand ] -> [ | Sand ]
